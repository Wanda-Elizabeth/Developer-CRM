# DevForge — Developer Growth Platform

> A full-stack platform where developers practice coding, find remote jobs, and connect with peers.

🌐 **Live Demo:** https://developer-crm-1.onrender.com

---

## What is DevForge?

DevForge is a developer community platform built to solve a real problem — the tools developers need to grow are scattered across too many apps.

DevForge brings together:
- **Coding challenges** generated by AI, twice a week
- **Remote job board** ranked by your skill match
- **Real-time community chat** (like a developer WhatsApp group)
- **Community feed** for sharing wins, asking questions, code reviews
- **Leaderboard** to track progress and stay accountable

---

## Features

- 🔐 JWT authentication (register, login, protected routes)
- 🧠 AI-generated weekly challenges via Groq (llama-3.3-70b)
- 💼 Live remote job board (Remotive + RemoteOK) ranked by your skills
- 💬 Real-time WebSocket chat — edit, delete, react to messages
- 🏆 Leaderboard with points, streaks, global ranking
- 👤 User profiles with skills, bio, GitHub, LinkedIn
- 🔔 Real-time notifications
- 🔍 Search across challenges, jobs, community, leaderboard
- 📱 Fully responsive — mobile nav, adaptive layouts

## Tech Stack

**Frontend**
- React + TypeScript
- Tailwind CSS
- Vite
- React Router

**Backend**
- Django + Django REST Framework
- Django Channels (WebSockets)
- Daphne (ASGI server)
- PostgreSQL
- JWT Authentication

**Infrastructure**
- Render (backend + frontend)
- GitHub Actions (automated challenge generation)
- Groq API (AI challenge generation)

## Running Locally

**Backend**
```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
daphne -p 8011 core.asgi:application
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```
